# About Markdownee
We included this in Airfox because Airfox runs on Markdownee.\
Markdownee is a content extraction and fetching engine that supports use with:
* An interactive playground
* Node
* npx
* Python
* Apify

Markdownee is based on:
* Cheerio
  * Crawlee
* [Trafilatura Core](https://www.trafilaturacore.com/)
  * [`adbar/trafilatura`](https://github.com/adbar/trafilatura)
  * [`markusmobius/go-trafilatura`](https://github.com/adbar/trafilatura) for DOM translation
 
for more info, see [Markdownee's Website](https://www.markdownee.com/)
